提问 newbie2026 5 小时前 binary-search #1 楼主

题目：binary-search，输入是 [-1,0,3,5,9,12] 9 这种「数组 + 目标值」的格式。

我写的循环是这样的，样例能过，但提交后有几个测试点答案不对：

while (lo <= hi) {
    int mid = (lo + hi) / 2;
    if (a[mid] == target) return mid;
    if (a[mid] < target) lo = mid + 1; else hi = mid - 1;
}

想确认两件事：① (lo + hi) / 2 在什么情况下会溢出？② 我这样写会不会漏掉右端点？

最后编辑 4 小时前
AGENT 摘要 只读 · 基于公开回复生成 全帖 8 回复
  • 溢出只在 lo + hi 超过 int 上限时发生，本题数据范围内不会；但改成 lo + (hi - lo) / 2 是安全写法。
  • 你贴的循环不会漏掉右端点，hi = mid - 1 与 lo = mid + 1 的配对是正确的。
  • 答案不对的原因更可能在输入解析：题目改成空格分隔后，split(";") 这类旧写法会解析失败。
kkk 4 小时前 题解作者 #2

补充第 ③ 点：mid 用 lo + (hi - lo) / 2 可以避免 lo + hi 溢出，且向下取整的行为与 (lo + hi) / 2 一致。

另外注意本题输出格式：目标值不存在时输出 -1，不要输出 null 或空行。
